Set a password first

Anyone who can reach this page could change the gold rate. Set a password before you use it — run this in the project folder: 

npm run setup

It asks for the ID and password you want — neither is shown on screen — and writes them to your .env file itself. The same command also switches on email. Restart the server afterwards and reload this page.
