# Word Tools

Small command-line utilities for working with text.

## Features

- Count words in a file
- Count unique words in a file

## Usage

```bash
python word_tools.py count path/to/file.txt
python word_tools.py unique path/to/file.txt
```

## Installation

No external depedencies required — just Python 3.8+.

## Running tests

```bash
python -m unittest discover tests
```
